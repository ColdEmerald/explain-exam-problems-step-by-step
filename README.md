# explain-exam-problems-step-by-step

一个面向考研与理工科学习场景的逐步讲题技能。它不只给出答案，还会从题型判断、第一眼突破口、公式来源到完整推导，帮助基础一般的学习者理解“为什么这样想、这一步为什么这样做”。

## 功能概述

本技能用于讲解、求解、分析和检查数学、信号与系统、通信、图像处理、电路、编程以及其他科学与工程类考试题、作业题。用户可以直接输入题目，也可以上传题目图片。

技能默认采用耐心、严谨的简体中文考研辅导风格，适合第一次接触相关题型、需要补齐基础概念或希望复盘解题思路的学习者。

## 主要特性

- 先复述题目、已知条件和所求，避免误读题意。
- 识别题型、直接考点、隐含考点和常用公式。
- 明确指出第一眼突破口，并解释由题目特征联想到方法的原因。
- 按“步骤—依据—目的”展开代数、积分、变换、分段、矩阵和程序执行过程。
- 首次出现术语、函数和符号时给出直观解释、正式定义及使用条件。
- 在标准解法之后，按适用条件补充可靠的快捷方法。
- 进行回代、验算、定义域、收敛域、因果稳定性、单位或边界条件检查。
- 总结可迁移的解题套路，列出常见错误及避免方法。
- 提供一道相近的变式题和自测检查点，促进举一反三。
- 支持公式追问、概念追问、选择题和编程题等特殊场景。

## 适用场景

- 考研数学、专业课和理工科课程复习。
- 根据题目截图进行识题与推导。
- 对某一步推导、公式来源或陌生函数进行追问。
- 复盘错题，定位计算错误、条件遗漏和方法选择错误。
- 学习选择题的标准推导与有边界的排除技巧。
- 逐行理解编程题中的变量变化、执行顺序和逻辑。

## 安装方法

### 作为 Codex 技能安装

1. 下载或克隆本仓库。
2. 将项目目录复制到 Codex 的技能目录 `$CODEX_HOME/skills/` 下。
3. 确认目录名保持为 `explain-exam-problems-step-by-step`，并且 `SKILL.md` 位于该目录根部。
4. 重新打开或刷新 Codex，使技能索引生效。

### 从技能包安装

也可以直接使用发布的 ZIP 压缩包。解压后保持以下结构，并将最外层项目目录放入技能目录：

```text
$CODEX_HOME/skills/explain-exam-problems-step-by-step/SKILL.md
$CODEX_HOME/skills/explain-exam-problems-step-by-step/agents/openai.yaml
```

本技能不需要额外的 Python 包、Node.js 包或第三方 API 密钥。它依赖支持技能加载的 Codex、ChatGPT、API 或 Atlas 运行环境。

## 配置说明

技能元数据位于 `agents/openai.yaml`：

- `display_name`：界面中显示的中文名称。
- `short_description`：技能列表中的简短说明。
- `default_prompt`：用户调用技能时使用的默认提示词。
- `policy.products`：声明支持的产品环境。
- `policy.allow_implicit_invocation`：设为 `true`，允许系统根据题目讲解请求自动调用技能。

通常无需修改配置。如果需要调整展示名称、默认提示词或启用范围，只需编辑该 YAML 文件，并保持合法的 YAML 格式。

## 调用示例

### 显式调用

```text
使用 $explain-exam-problems-step-by-step 按固定流程详细讲解这道题，重点说明每一步为什么这样想。
```

### 直接提出题目

```text
请逐步讲解这道信号与系统题，先判断题型，再说明第一眼突破口，最后给一道相近的变式题。
```

### 追问公式来源

```text
这个公式是怎么来的？请说明它解决什么问题、成立条件，以及在本题中如何代入。
```

### 上传图片

上传题目截图后，可以补充：

```text
请先准确识别图片中的题目。如果符号或条件看不清，请指出不确定的位置，不要猜测，然后按完整流程讲解。
```

## 技术架构

本项目采用轻量级声明式技能架构：

1. `SKILL.md` 使用 Markdown 描述技能的适用范围、核心原则、固定回答流程和特殊情形处理规则。
2. `agents/openai.yaml` 提供产品侧展示信息、默认提示词和隐式调用策略。
3. 运行时由宿主模型读取技能指令，并结合用户题目生成结构化、可验证的中文讲解。

项目没有业务代码和运行时服务，因此不需要编译、数据库或外部依赖。数学公式通常使用 Markdown/LaTeX 形式表达；编程题则根据题目语言给出带有适合初学者的代码注释和执行跟踪。
