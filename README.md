# explain-exam-problems-step-by-step

一个面向考研与理工科学习场景的逐步讲题技能。它不只给出答案，还会从题型判断、第一眼突破口、公式来源到完整推导，帮助基础一般的学习者理解"为什么这样想、这一步为什么这样做"。

## 功能概述

本技能用于讲解、求解、分析和检查数学、信号与系统、通信、图像处理、电路、编程以及其他科学与工程类考试题、作业题。用户可以直接输入题目，也可以上传题目图片。

技能默认采用耐心、严谨的简体中文考研辅导风格，适合第一次接触相关题型、需要补齐基础概念或希望复盘解题思路的学习者。

## 主要特性

- **意图识别与模式选择**：自动区分"完整讲解"与"直接给答案"请求，避免对简单计算题输出冗余的 8 步流程。
- **三级讲解模式**：简明模式（3 步）/ 标准模式（8 步）/ 深度模式（8 步 + 多轮追问延续）。
- **图片题安全协议**：识别歧义符号后暂停推导，列出不确定位置并等待用户确认，不猜造内容。
- 先复述题目、已知条件和所求，避免误读题意。
- 识别题型、直接考点、隐含考点和常用公式。
- 明确指出第一眼突破口，并解释由题目特征联想到方法的原因。
- 按"步骤—依据—目的"展开代数、积分、变换、分段、矩阵和程序执行过程。
- 首次出现术语、函数和符号时给出直观解释、正式定义及使用条件。
- 在标准解法之后，按适用条件补充可靠的快捷方法。
- 进行回代、验算、定义域、收敛域、因果稳定性、单位或边界条件检查。
- 总结可迁移的解题套路，列出常见错误及避免方法。
- 提供一道相近的变式题和自测检查点，促进举一反三；回复"讲解变式题"可触发完整解析。
- 支持多问综合大题的子问依赖管理、公式追问、概念追问、选择题和编程题等特殊场景。

## 适用场景

- 考研数学、专业课和理工科课程复习。
- 根据题目截图进行识题与推导。
- 对某一步推导、公式来源或陌生函数进行追问。
- 复盘错题，定位计算错误、条件遗漏和方法选择错误。
- 学习选择题的标准推导与有边界的排除技巧。
- 逐行理解编程题中的变量变化、执行顺序和逻辑。

## 安装方法

### 作为 Codex / Antigravity 技能安装

1. 下载或克隆本仓库。
2. 将项目目录复制到技能目录（Codex: `$CODEX_HOME/skills/`；Antigravity: 参见 AGY 文档中的技能路径）。
3. 确认目录名保持为 `explain-exam-problems-step-by-step`，并且 `SKILL.md` 位于该目录根部。
4. 重新打开或刷新宿主应用，使技能索引生效。

### 从技能包安装

也可以直接使用发布的 ZIP 压缩包。解压后保持以下结构，并将最外层项目目录放入技能目录：

```text
$SKILLS_HOME/explain-exam-problems-step-by-step/SKILL.md
$SKILLS_HOME/explain-exam-problems-step-by-step/agents/agent.yaml
```

本技能不需要额外的 Python 包、Node.js 包或第三方 API 密钥。它依赖支持技能加载的 Codex、ChatGPT、API、Atlas 或 Antigravity 运行环境。

## 配置说明

技能元数据位于 `agents/agent.yaml`：

- `display_name`：界面中显示的中文名称。
- `short_description`：技能列表中的简短说明。
- `default_prompt`：用户调用技能时使用的默认提示词。
- `policy.products`：声明支持的产品环境。
- `policy.allow_implicit_invocation`：设为 `true`，允许系统根据题目讲解请求自动调用技能。

通常无需修改配置。如果需要调整展示名称、默认提示词或启用范围，只需编辑该 YAML 文件，并保持合法的 YAML 格式。

## 调用示例

### 显式调用（标准模式）

```text
使用 $explain-exam-problems-step-by-step 按固定流程详细讲解这道题，重点说明每一步为什么这样想。
```

### 直接提出题目

```text
请逐步讲解这道信号与系统题，先判断题型，再说明第一眼突破口，最后给一道相近的变式题。
```

### 简明模式（只要答案）

```text
帮我算一下这道积分题，直接给结果就行。
```

### 追问公式来源

```text
这个公式是怎么来的？请说明它解决什么问题、成立条件，以及在本题中如何代入。
```

### 触发变式题讲解

```text
讲解变式题
```

### 上传图片

上传题目截图后，可以补充：

```text
请先准确识别图片中的题目。如果符号或条件看不清，请列出不确定的位置，不要猜测，然后按完整流程讲解。
```

## 技术架构

本项目采用轻量级声明式技能架构：

1. `SKILL.md` 使用 Markdown 描述技能的适用范围、核心原则、固定回答流程和特殊情形处理规则；各节使用 HTML 注释锚点（如 `<!-- section: main-flow -->`）便于差分追踪与局部覆盖。
2. `agents/agent.yaml` 提供产品侧展示信息、默认提示词和隐式调用策略。
3. 运行时由宿主模型读取技能指令，并结合用户题目生成结构化、可验证的中文讲解。
4. `examples/` 提供**回归基准**：16 个固定样本（信号与系统 6、考研数学 6、特殊情形 4），配合 `check.py` 的确定性检查与 `RUBRIC.md` 的人工/judge 评分规则，用于验证 `SKILL.md` 改动后输出质量是否退化。该目录**不参与技能运行时**，模型推理时不会读取。

项目没有业务代码和运行时服务，因此不需要编译、数据库或外部依赖。数学公式使用 LaTeX 形式（`$...$` / `$$...$$`）表达，平台不支持时退化为 ASCII 数学表达；编程题则根据题目语言给出带有适合初学者的代码注释和执行跟踪。

## 回归基准

`examples/` 是本项目的质量护栏。本技能是纯声明式的——没有可执行代码，因此「测试」只能落在模型输出的文本上。仓库提供：

- **16 个固定样本**，覆盖 `SKILL.md` 中最容易退化的规则分支（分段讨论、积分区间、变换域、矩阵维度、程序执行过程、收敛域、因果稳定性），以及全部特殊情形（公式追问、概念追问、选择题、编程题、图片题、多问大题）。
- **两级基线**：Tier A 含人工审定的参考输出（10 份），锚定输出风格与深度；Tier B 仅含检查清单（6 份），只校验结构与关键事实，维护成本低。
- **`check.py`**：零第三方依赖的确定性检查器，校验章节齐全性、关键词、禁语、关键结论与 token 组合约束。
- **`RUBRIC.md`**：五维质量评分标准（推导完整性、依据正确性、验算完备性、教学价值、表达质量）与 LLM-as-judge 提示词模板。

快速上手：

```bash
python examples/check.py --list
python examples/check.py --sample signal-systems/01-laplace-inverse --show
python examples/check.py --sample signal-systems/01-laplace-inverse --output out.md
```

修改 `SKILL.md` 后的标准回归流程见 `examples/RUBRIC.md` 末节。

## 贡献建议

欢迎通过 Issue 或 Pull Request 提出改进建议。新增规则时请保持以下原则：
- 内容使用简体中文。
- 关键推导不可跳步，明确适用条件。
- 避免用未经说明的技巧替代标准解法。
- 新增学科只需在 `SKILL.md` 的"适用学科"节追加，无需修改其他文件。
- PR 描述请按节/规则粒度说明变更内容（如"更新：第 6 步易错点范围从强制 3–5 改为按需"）。
- **修改 `SKILL.md` 时请同步跑一遍回归基准**（`examples/RUBRIC.md` 末节有标准流程）。若改动影响到某个样本锁定的规则，请在 PR 中说明，并按需更新该样本的 `checks.json` 或 `reference.md`。
- 新增样本请复制 `examples/_template/`，并说明该样本锁定了哪条规则。
