# 参考输出：01 选择题的标准推导与排除法

> 人工审定的基准输出。核心是「先标准推导、再排除技巧、并说明技巧边界」三段式。

## 题型判断与考点

**题型**：单项选择题（傅里叶变换的基本计算）。

**直接考点**：$e^{-at}u(t)$ 的傅里叶变换。

**隐含考点**：
- 傅里叶变换的定义式与收敛条件（$a>0$ 时积分收敛）；
- 干扰项设计的意图：系数错、符号错、混入时移因子；
- 排除法的**适用边界**——它只在选项互斥且可用特殊值检验时可靠。

**常用公式**：

$$
X(j\omega) = \int_{-\infty}^{\infty}x(t)e^{-j\omega t}\mathrm{d}t,\qquad \mathcal{F}\{e^{-at}u(t)\} = \frac{1}{a+j\omega}\ (a>0)
$$

**命题人想考察什么**：基本变换对是否扎实，以及能否在选择题的约束下组织出「推导 + 验证」的完整回答。

## 第一眼突破口

**看到的第一样东西**：$x(t)=e^{-2t}u(t)$，选项里全是形如 $\frac{\text{系数}}{2\pm j\omega}$ 的表达式。

**由此联想到什么**：$e^{-at}u(t)$ 是**最标准的**傅里叶变换对之一，$a=2$ 直接代入得 $\frac{1}{2+j\omega}$。这与选项 A 完全一致。

**关键的第二层观察**：不过「一眼看出答案」对选择题而言是不够的——需要说明**为什么其他选项错**，否则一旦模型记错了变换对就会盲目选 A。所以正确做法是先做标准推导得到权威结果，再用排除法独立验证。

**因此选择的路线**：标准推导定答案 → 排除法逐项验证 → 说明排除技巧的边界。

## 逐步推导

### 第一步：确认符号含义

**做什么**：明确各符号。

**依据**：$u(t)$ 为单位阶跃函数，$u(t)=1$ 当 $t\ge0$，否则为 0；$j$ 为虚数单位。

**说明**：$x(t)$ 在 $t<0$ 时恒为零，在 $t\ge0$ 时按 $e^{-2t}$ 衰减。

### 第二步：用定义式做标准推导

**做什么**：直接由定义式计算。

**依据**：$X(j\omega) = \int_{-\infty}^{\infty} x(t)e^{-j\omega t}\mathrm{d}t$。

**代入并利用 $u(t)$ 截断**：

$$
X(j\omega) = \int_{-\infty}^{\infty} e^{-2t}u(t)e^{-j\omega t}\mathrm{d}t = \int_0^{\infty} e^{-(2+j\omega)t}\mathrm{d}t
$$

**计算**：由 $\int_0^\infty e^{-at}\mathrm{d}t = \frac{1}{a}$（收敛条件 $\mathrm{Re}(a)>0$），此处 $a = 2+j\omega$，$\mathrm{Re}(a)=2>0$ ✓ 满足。

$$
X(j\omega) = \frac{1}{2+j\omega}
$$

**收敛条件说明**：对任何实数 $\omega$，$\mathrm{Re}(2+j\omega)=2>0$，所以该傅里叶变换对**所有** $\omega$ 都存在。

**目的**：得到权威结果。

### 第三步：用「$\omega=0$ 代入」做独立检验

**做什么**：取 $\omega=0$ 计算 $X(0)$，与各选项对比。

**依据**：$X(0) = \int_{-\infty}^{\infty}x(t)\mathrm{d}t$，即信号的面积（直流分量）。

**计算**：

$$
X(0) = \int_0^{\infty}e^{-2t}\mathrm{d}t = \frac{1}{2} = 0.5
$$

**逐项代入 $\omega=0$**：

- A：$\frac{1}{2+0} = \frac{1}{2} = 0.5$ ✓
- B：$\frac{2}{2+0} = 1$ ✗
- C：$\frac{1}{2}\cdot e^{0} = 0.5$ —— 数值上**恰好也通过**！需要进一步检验
- D：$\frac{1}{2-0} = 0.5$ —— 数值上**也通过**！

**这里必须停一下**：$\omega=0$ 检验只能排除 B，对 C 和 D 无效。因为 $\omega=0$ 时 $e^{-j\omega t}=1$、$j\omega=0$，很多错误形式在此处「恰好退化为正确值」。

**这正是排除技巧的边界所在**——需要换检验点。

### 第四步：换检验点——$\omega$ 的奇偶对称性

**做什么**：利用 $x(t)$ 为**实偶信号**这一性质。

**依据**：实偶信号的傅里叶变换是**实偶函数**，即 $X(-j\omega) = X(j\omega) \in \mathbb{R}$。

**理由**：$x(t)$ 实且偶 $\Rightarrow$ 变换为实且偶。

**检验各选项的奇偶性**：

- A：$X(j\omega)=\frac{1}{2+j\omega}$，取共轭 $\frac{1}{2-j\omega}$，与 $\frac{1}{2+j\omega}$ **不相等**，且不是实数（当 $\omega\neq0$ 时分母有虚部）。**但它确实是偶函数**（$\frac{1}{2+j(-\omega)}=\frac{1}{2-j\omega}$，与 $X(j\omega)$ 互为共轭——注意：$X(j\omega)$ 本身不是实数！

**这里必须重新审视**：$x(t)=e^{-2t}u(t)$ 是**实信号但不是偶信号**（只在 $t\ge0$ 非零）。所以 $X(j\omega)$ 是**复函数**，不是实的。

**修正判据**：实信号 ⟹ 变换满足**共轭对称性** $X(-j\omega) = X^*(j\omega)$。

**逐项检验共轭对称性**：

- A：$X(j\omega)=\frac{1}{2+j\omega}$。$X(-j\omega)=\frac{1}{2-j\omega}$，而 $X^*(j\omega) = \frac{1}{2-j\omega}$ ✓ 满足
- B：$X^*(j\omega) = \frac{2}{2-j\omega}$，$X(-j\omega)=\frac{2}{2-j\omega}$ ✓ 满足（对称性检验不区分 A 与 B）
- C：多出因子 $e^{-j\omega t}$，其中 **$t$ 是变量不是常数**——这本身就是**量纲与形式错误**：傅里叶变换的结果不应含有原变量 $t$。✗ 直接排除
- D：$X(j\omega)=\frac{1}{2-j\omega}$。$X^*(-j\omega)$ 检查：$X(-j\omega)=\frac{1}{2+j\omega}$，而 $X^*(j\omega)=\frac{1}{2+j\omega}$ ✓ 也满足对称性

**对称性检验排除不了 A 与 D**——需要换思路。

### 第五步：用「衰减/稳定直觉」区分 A 与 D

**做什么**：考察 $\omega\to+\infty$ 与 $\omega\to-\infty$ 的行为。

**依据**：$e^{-2t}u(t)$ 是**因果**信号，其频谱的相位应随 $\omega$ 呈**负斜率**演化（延时使相位滞后）。

**检验**：$X(j\omega)=\frac{1}{2+j\omega}$ 的相位为 $-\arctan\frac{\omega}{2}$，随 $\omega$ 增大而单调下降，在 $\omega\to+\infty$ 时趋于 $-\frac{\pi}{2}$。

而 D 的 $\frac{1}{2-j\omega}$ 相位为 $+\arctan\frac{\omega}{2}$，趋于 $+\frac{\pi}{2}$。

**物理判据**：对因果信号 $e^{-at}u(t)$，其频谱可写为

$$
\frac{1}{a+j\omega} = \frac{a-j\omega}{a^2+\omega^2} = \frac{1}{a}\cdot\frac{1 - j\frac{\omega}{a}}{1+(\frac{\omega}{a})^2}
$$

即实部为偶函数（正）、虚部为**奇函数且为负**（当 $\omega>0$）。这与「实信号 + 因果性」一致。D 的虚部为正，与因果信号不符。

**更简单的检验**：直接看 $\omega$ 的符号约定。$\mathcal{F}\{x(t)\}=\int x(t)e^{-j\omega t}\mathrm{d}t$ 中是 $e^{-j\omega t}$，代入 $e^{-2t}$ 得 $\int_0^\infty e^{-(2+j\omega)t}\mathrm{d}t$，分母必为 $2+j\omega$（$+j\omega$）。D 的 $2-j\omega$ 对应的是 $e^{+j\omega t}$ 的约定，与题目给出的标准约定不符 ✗

**结论**：D 的符号与 $e^{-j\omega t}$ 约定冲突，排除。

### 第六步：汇总判定

**标准推导结果**：$X(j\omega)=\frac{1}{2+j\omega}$

**排除过程**：

| 选项 | 排除依据 |
|---|---|
| B | $\omega=0$ 处面积为 $\frac{1}{2}$，B 给出 1，系数错（把 $1/(a+j\omega)$ 的 $a$ 丢了） |
| C | 结果中出现原变量 $t$，形式错误（时移因子不能出现在频域结果中） |
| D | 符号与 $e^{-j\omega t}$ 约定冲突，且虚部符号与因果信号不符 |

**答案**：**A**

## 解题思维复盘

**从题目特征回到方法选择**：$e^{-at}u(t)$ 是最标准的变换对之一，看到 $a=2$ 应当直接想起 $\frac{1}{2+j\omega}$。但选择题要的是**排除其他项**，所以标准推导只是第一步。

**为什么排除法需要多个检验点**：本题暴露了一个重要事实——$\omega=0$ 代入只能排除 B，对 C（形式错误）与 D（符号错误）完全无效。**每个干扰项的错误类型不同，就需要针对不同错误类型设计检验**。

**干扰项的分类与对策**：

| 错误类型 | 本题例子 | 对策 |
|---|---|---|
| 系数错误 | B | 代入 $\omega=0$（面积检验） |
| 形式错误（残留时变量） | C | 检查结果中是否含 $t$ |
| 符号/约定错误 | D | 检查 $e^{-j\omega t}$ 约定的符号 |

**常见错误路线为什么走不通**：
- 只用 $\omega=0$ 检验就宣布排除完毕——会漏掉 C 和 D；
- 用「感觉 $e^{-at}u(t)$ 就是 $\frac{1}{a+j\omega}$」直接选 A 而不做任何排除——在本题答案恰好是 A，但换个题就可能错；
- 认为排除法「总是可靠」——它只在选项互斥、且检验点能区分时可靠。

## 核心套路总结

> **看到什么 → 想到什么 → 怎么做 → 检查什么**

**看到什么**：单选题 + 若干形似的表达式选项。

**想到什么**：先找最直接的标准方法得到权威答案，再针对每个干扰项的错误类型设计检验。

**怎么做**：
1. **标准推导**：用定义式或已知变换对算出结果，写清依据与收敛条件；
2. **分类错误**：逐个判断干扰项属于哪类错误（系数/形式/符号/适用条件）；
3. **针对性排除**：为每类错误设计一个检验（特殊值代入、形式检查、约定核对）；
4. **说明边界**：明确指出排除法的适用条件与失效场景。

**检查什么**：每个选项都被排除（不能只排一部分）；排除依据针对的是该选项的**具体**错误类型；最终答案与标准推导一致。

## 易错点

1. **错误表现**：给出推导后不排除任何选项，直接宣布答案。
   **错误原因**：认为选择题只需一个答案。
   **避免方法**：`SKILL.md` 要求「先给标准推导，再补充选项排除法」，两者都要有。

2. **错误表现**：只用 $\omega=0$ 代入就以为排除了全部。
   **错误原因**：单一检验点的分辨力有限。
   **避免方法**：换检验点（形式检查、约定核对）直到每个选项都有专属依据。

3. **错误表现**：未说明排除技巧的适用边界。
   **错误原因**：把技巧当成万能手段。
   **避免方法**：明确写出「排除法依赖选项互斥且检验点有区分力；单检验点不足以区分全部选项时需换点」。

4. **错误表现**：结果中保留了 $e^{-j\omega t}$ 这类含 $t$ 的项。
   **错误原因**：把时域表达式直接搬到频域。
   **避免方法**：频域结果不应含原变量 $t$；若出现，说明变换未完成。

5. **错误表现**：不检查收敛条件。
   **错误原因**：认为变换对「总是存在」。
   **避免方法**：写明 $\mathrm{Re}(a)>0$ 一类的存在条件，本题 $a=2$ 满足。

## 更快捷的方法

**方法**：对「$e^{-at}u(t)$ 的傅里叶变换」这类**标准变换对**的选择题，直接写出 $\frac{1}{a+j\omega}$，然后**只用一个高信息量的检验点**排除全部干扰项——例如取 $\omega\to\infty$ 看渐近行为（分子为 1、分母的一次项），或检查结果中是否残留 $t$。

**适用条件**：题目考的是**已知变换对**且干扰项错误类型明确。

**快在哪里**：一个检验点覆盖一类错误。

**为什么成立**：不同错误类型会在不同检验点暴露出来。

**说明**：本题的标准解法已足够；快捷法适合考场快速排除，但不能替代「说明边界」这一步。

## 同类型变式题

**变式题**（单选题）：信号 $x(t) = e^{-2t}u(-t)$ 的傅里叶变换 $X(j\omega)$ 是：

A. $\dfrac{1}{2+j\omega}$

B. $\dfrac{1}{2-j\omega}$

C. $\dfrac{-1}{2-j\omega}$

D. $\dfrac{1}{j\omega-2}$

**它训练的识别点**：**$u(-t)$ 与 $u(t)$ 的变换只差一个负号与 $j\omega$ 的符号**。正确答案应为 $-\frac{1}{2-j\omega}$（即选项 C）。这直接检验学生是否真正区分了左右边信号——原题中四个选项的错误类型（系数、残留变量、符号）都不涉及「左右向」这个维度。

**同时**：本题中 A 与 D 是原题正确选项的「陷阱版」，能看出学生是套用记忆还是重新推导。

**自测检查点**：先由定义式算 $\int_{-\infty}^0 e^{-(2-j\omega)t}\mathrm{d}t$，注意积分限为负，代入 $\int_{-\infty}^0 e^{-at}\mathrm{d}t = -\frac{1}{a}$（收敛条件 $\mathrm{Re}(a)<0$，此处 $a=2-j\omega$ 不满足，需重新判断）。

**最终答案**：C。

回复「讲解变式题」可看完整推导。
