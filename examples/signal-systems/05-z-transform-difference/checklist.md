### 关键结论（机器可检）

- 给出系统函数 H(z)：命中 `\frac{1}{(1-0.25z^{-1})^2}` / `1/(1-0.25z^{-1})^2` / `\frac{z^2}{(z-0.25)^2}` 之一即可
- 给出冲激响应中的 n 因子（重根特征）：命中 `n\cdot` / `n(` / `(n+1)` / `0.25^n` 之一即可

### token 组合约束（机器可检）

- 出现 0.25 的幂次项；须同时出现 `0.25`

### 结论必须缺席（机器可检）

- （无）

### 质量（人工或 judge）

- 维度 1（推导完整性）：重根导致部分分式展开需引入 $n$ 因子，这一步不能跳
- 维度 3（验算完备性）：稳定性需由 ROC 是否包含单位圆判定

## 判退场景

出现以下任一情况即判定不合格：

- 按两个不同极点处理，遗漏 n 因子
- 稳定性判断未联系 ROC 与单位圆

## 备注

重根是 Z 变换的高频陷阱。特征方程的根在题面中给出，避免了学生算错根而无法归因于技能本身；但「重根 → 需引入 n 因子」这一步仍需技能完整展示。
