# 参考输出：03 傅里叶级数与狄利克雷收敛条件

> 人工审定的基准输出。核心是系数推导与跳变点收敛值讨论必须同时到位。

## 题型判断与考点

**题型**：三角形式傅里叶级数展开 + 收敛性分析。

**直接考点**：$a_n$、$b_n$ 系数的定义式计算；狄利克雷收敛定理。

**隐含考点**：
- 系数被积函数的**奇偶性**——本题 $x(t)$ 为偶函数，故 $b_n=0$，只需算 $a_n$；
- 狄利克雷条件：函数在周期内分段连续、极值有限；
- 收敛点取值为**左右极限的平均值**，而非函数在该点的定义值。

**常用公式**：

$$
a_n = \frac{1}{\pi}\int_{-\pi}^{\pi} x(t)\cos(nt)\,\mathrm{d}t,\qquad b_n = \frac{1}{\pi}\int_{-\pi}^{\pi} x(t)\sin(nt)\,\mathrm{d}t
$$

**命题人想考察什么**：能否利用对称性简化系数计算，并在求出级数后正确判断每个边界点的收敛值。

## 第一眼突破口

**看到的第一样东西**：$x(t)$ 的定义中，只有 $|t|<\frac{\pi}{2}$ 时为 1，其余为 0，且关于原点**对称**。

**由此联想到什么**：$x(t)$ 是**偶函数**，所以 $\sin(nt)$ 是奇函数、$\cos(nt)$ 是偶函数。由 $b_n$ 积分式中奇函数乘偶函数积分为零，得 $b_n = 0$；由 $a_n$ 积分式中偶函数乘偶函数积分为偶积分，得

$$
a_n = \frac{2}{\pi}\int_0^{\pi} x(t)\cos(nt)\,\mathrm{d}t
$$

这一步把积分区间从 $[-\pi,\pi]$ 缩到 $[0,\pi]$，是本题第一个关键简化。

**关键的第二层观察**：$x(t)$ 的两个跳变点在 $t=\pm\frac{\pi}{2}$，而 $t=\pm\pi$ 是**周期延拓的接缝处**——接缝处左右极限相同（都是 1），所以不是跳变。两类点的收敛值不同，这正是本题的考点。

**因此选择的路线**：先用对称性化简系数积分，再逐点讨论收敛值。

## 逐步推导

### 第一步：确定系数形式

**做什么**：判断哪些系数需要计算。

**依据**：$x(t)$ 为偶函数，$x(t)\sin(nt)$ 为奇函数，在对称区间上积分为零。

**结论**：$b_n = 0$，只需计算 $a_n$。$a_0$ 单独计算：

$$
a_0 = \frac{1}{\pi}\int_{-\pi}^{\pi} x(t)\,\mathrm{d}t = \frac{2}{\pi}\int_0^{\pi/2} 1\,\mathrm{d}t = \frac{2}{\pi}\cdot\frac{\pi}{2} = 1
$$

### 第二步：计算 $a_n$（$n \ge 1$）

**做什么**：分段积分。

**依据**：被积函数 $x(t)\cos(nt)$ 在 $[0,\pi]$ 上仍需按 $x(t)$ 的定义分段，因为 $x(t)$ 在 $t=\frac{\pi}{2}$ 处跳变。

**分段写清**：

$$
a_n = \frac{2}{\pi}\left[\int_0^{\pi/2} \cos(nt)\,\mathrm{d}t + \int_{\pi/2}^{\pi} 0 \cdot \cos(nt)\,\mathrm{d}t\right] = \frac{2}{\pi}\int_0^{\pi/2}\cos(nt)\,\mathrm{d}t
$$

**计算**：

$$
\int_0^{\pi/2}\cos(nt)\,\mathrm{d}t = \left[\frac{\sin(nt)}{n}\right]_0^{\pi/2} = \frac{\sin(n\pi/2)}{n}
$$

**故**：

$$
a_n = \frac{2}{n\pi}\sin\frac{n\pi}{2}, \qquad n \ge 1
$$

**目的**：得到系数的闭式，并看清它的周期结构。

### 第三步：分析系数的奇偶次结构

**做什么**：把系数按 $n$ 的奇偶分类化简。

**依据**：$\sin\frac{n\pi}{2}$ 在 $n$ 为偶数时为 0，在 $n$ 为奇数时为 $\pm 1$。

**逐类展开**：

- $n = 1$：$\sin\frac{\pi}{2} = 1$，$a_1 = \frac{2}{\pi}$
- $n = 2$：$\sin\pi = 0$，$a_2 = 0$
- $n = 3$：$\sin\frac{3\pi}{2} = -1$，$a_3 = -\frac{2}{3\pi}$
- $n = 4$：$0$
- $n = 5$：$\sin\frac{5\pi}{2} = 1$，$a_5 = \frac{2}{5\pi}$

**规律**：偶次谐波全部为零，奇次谐波交替取 $\frac{2}{n\pi}$ 与 $-\frac{2}{n\pi}$。

**写成紧凑形式**（$n=1,3,5,\dots$）：

$$
a_n = \frac{2}{n\pi}(-1)^{\frac{n-1}{2}}
$$

**为什么偶次谐波消失**：本题的 $x(t)$ 是一个**对称的矩形脉冲**，其频谱关于 $\omega=0$ 对称且以 $\omega=2\pi$ 为周期，这种结构必然导致偶次谐波为零。这不是巧合，而是方波信号的固有特征。

### 第四步：写出级数

$$
x(t) = \frac{a_0}{2} + \sum_{n=1}^{\infty}a_n\cos(nt) = \frac{1}{2} + \sum_{n=1,3,5,\dots}\frac{2}{n\pi}(-1)^{\frac{n-1}{2}}\cos(nt)
$$

**展开前几项**：

$$
x(t) = \frac{1}{2} + \frac{2}{\pi}\cos t - \frac{2}{3\pi}\cos 3t + \frac{2}{5\pi}\cos 5t - \cdots
$$

**校验**：常数项 $\frac{1}{2}$ 是方波的平均值，符合直觉——正负半周各占一半。

### 第五步：讨论收敛点（本题核心）

**做什么**：用狄利克雷定理逐点判断。

**依据**：狄利克雷收敛定理——若函数在一周期内分段连续、只有有限个极值点，则级数在每一点收敛到该点左右极限的**平均值**：

$$
\frac{x(t^+) + x(t^-)}{2}
$$

**逐点分析**：

**（1）跳变点 $t = \pm\frac{\pi}{2}$**：
左边极限 $x(\frac{\pi}{2}^-) = 1$，右边极限 $x(\frac{\pi}{2}^+) = 0$，故收敛到

$$
\frac{1+0}{2} = \frac{1}{2}
$$

注意：**不是 0，也不是 1，而是 $\frac{1}{2}$**。这是本样本最重要的单点结论。

**（2）连续点 $-\frac{\pi}{2} < t < \frac{\pi}{2}$**：左右极限都是 1，级数收敛到 1，与 $x(t)$ 相符。

**（3）连续点 $\frac{\pi}{2} < |t| < \pi$**：左右极限都是 0，收敛到 0。

**（4）周期接缝 $t = \pm\pi$**：这里需要特别注意。$x(t)$ 在 $-\pi$ 处定义为 0（因为 $|t|>\frac{\pi}{2}$），而由周期性，$x(-\pi^+)$ 的左极限来自上一周期末端的 1（因为在 $-\pi$ 右侧极远处即上一周期的 $\frac{\pi}{2}$ 之后，函数值为 0）——让我们仔细算：周期为 $2\pi$，所以 $x(-\pi^+) = x(\pi^-) = 0$，而 $x(-\pi^-) = x(-\pi^-)$，即从左侧（即小于 $-\pi$ 的方向）趋近时对应的是 $x(\pi^-)$，也是 0。

更稳妥的算法：$t=-\pi$ 处的左极限等于 $t=\pi$ 处的左极限（相差一个周期），即 $x(-\pi^-) = x(\pi^-) = 0$；右极限 $x(-\pi^+) = x(\pi^+) = 0$。两者均为 0，所以级数在 $t=\pm\pi$ 处收敛到 **0**。

**这里的常见误解**：认为「接缝处函数定义为 0，所以收敛到 0」是对的，但理由必须基于左右极限而非定义值——在本题中两者恰好一致，但若题目改成 $x(t)$ 在端点处定义不同，结论就要重新按左右极限算。

**（5）任意其他点**：左右极限相同，级数收敛到 $x(t)$ 本身。

### 第六步：验算（Parseval 定理）

**验算目的**：用能量守恒核对系数。

**依据**：Parseval 定理 $\frac{1}{\pi}\int_{-\pi}^{\pi}|x(t)|^2\mathrm{d}t = \frac{a_0^2}{2} + \sum_{n=1}^{\infty}(a_n^2+b_n^2)$。

**左边**：$\frac{1}{\pi}\int_{-\pi}^{\pi}x^2(t)\mathrm{d}t = \frac{1}{\pi}\cdot 2\cdot\int_0^{\pi/2}1\,\mathrm{d}t = \frac{1}{\pi}\cdot 2\cdot\frac{\pi}{2} = 1$

**右边**：$\frac{a_0^2}{2} + \sum_{n=1,3,5,\dots}\frac{4}{n^2\pi^2} = \frac{1}{2} + \frac{4}{\pi^2}\sum_{n=1,3,5,\dots}\frac{1}{n^2}$

而 $\sum_{n=1,3,5,\dots}\frac{1}{n^2} = \left(1-\frac{1}{4}\right)\frac{\pi^2}{6} = \frac{\pi^2}{8}$

故右边 $= \frac{1}{2} + \frac{4}{\pi^2}\cdot\frac{\pi^2}{8} = \frac{1}{2}+\frac{1}{2} = 1$ ✓

**两边相等，验算通过。**

## 解题思维复盘

**从题目特征回到方法选择**：看到「矩形脉冲 + 偶对称」，第一反应应该是「先化简系数积分，再单独处理跳变点」，而不是直接展开被积函数积分。

**为什么对称性是第一步**：它把积分区间减半、把 $b_n$ 整族消掉，直接省掉一半工作量。在任何含三角函数的系数计算中，**先看奇偶性**是固定的第一步。

**常见错误路线为什么走不通**：
- 只算系数不讨论收敛点——这是最常见的失分点，因为题目明确问了；
- 认为 $t=\pm\frac{\pi}{2}$ 处收敛到 0 或 1——狄利克雷定理说的是**左右极限的平均值**，跳变处必然是中间值；
- 混淆 $t=\pm\pi$（周期接缝）与 $t=\pm\frac{\pi}{2}$（真实跳变）——接缝处不是跳变，收敛值是 0 而非 $\frac{1}{2}$。

## 核心套路总结

> **看到什么 → 想到什么 → 怎么做 → 检查什么**

**看到什么**：周期信号 + 明确的分段定义。

**想到什么**：先看奇偶性决定要算哪些系数；再看跳变点在哪、周期接缝在哪。

**怎么做**：
1. 用奇偶性把系数积分化简（偶函数只需算 $a_n$，奇函数只需算 $b_n$）；
2. 分段积分，每段明确写出 $x(t)$ 的取值；
3. 把系数整理成按 $n$ 奇偶分类的紧凑形式；
4. 列出**所有**需要讨论的边界点：真实跳变点 + 周期接缝；
5. 逐点用「左右极限平均值」给出收敛值。

**检查什么**：Parseval 定理验算；跳变点收敛值是否落在左右极限之间；周期接缝是否被误当成跳变。

## 易错点

1. **错误表现**：跳变点收敛值写成 0 或 1。
   **错误原因**：直接代入函数定义值，未用狄利克雷定理。
   **避免方法**：牢记收敛值 = 左右极限平均值，跳变处必为中间值 $\frac{1}{2}$。

2. **错误表现**：把 $t=\pm\pi$ 也当成跳变点，收敛值写成 $\frac{1}{2}$。
   **错误原因**：未区分「真实跳变」与「周期延拓接缝」。
   **避免方法**：接缝处的左右极限来自相邻两周期，需按周期折算后比较。本题两侧都是 0，收敛到 0。

3. **错误表现**：算出 $b_n$ 却发现全是 0 后，仍继续计算并怀疑自己。
   **错误原因**：未先判断奇偶性。
   **避免方法**：见到三角形式系数，先判断被积函数的奇偶性，可省一半工作。

4. **错误表现**：系数写成 $\frac{2}{n\pi}\sin\frac{n\pi}{2}$ 后未整理，直接以级数形式收尾。
   **错误原因**：未指出奇偶次谐波的结构规律。
   **避免方法**：把系数按 $n$ 的奇偶分类化简，这既便于核对，也是变式题的关键。

5. **错误表现**：未做端点讨论，只给了系数和级数。
   **错误原因**：把「求傅里叶级数」与「讨论收敛性」当作两件事，忽略题目要求。
   **避免方法**：逐字读题目，确认每一个问。

## 更快捷的方法

**方法**：用「方波 = 符号函数」的标准展开式：

$$
\operatorname{sgn}(\cos t) = \frac{4}{\pi}\left(\cos t - \frac{\cos 3t}{3} + \frac{\cos 5t}{5} - \cdots\right)
$$

本题的 $x(t)$ 恰是宽度为 $\pi$ 的矩形脉冲，可由上式平移缩放得到；等价地，本题结果也就是这一标准式的「移动 + 取反」版本。

**适用条件**：波形为对称矩形脉冲且周期已明确时。

**快在哪里**：直接写出系数规律，跳过积分。

**为什么成立**：这是同一个数学对象的不同参数化，属于结论复用而非近似。

**说明**：本题中标准解法（先化简再积分）已经足够清晰，快捷法仅适合心算核对。

## 同类型变式题

**变式题**：求周期为 $2\pi$ 的信号

$$
x(t) = \begin{cases} t, & 0 < t < \pi \\ 0, & -\pi < t < 0 \end{cases}
$$

的傅里叶级数，并讨论 $t=0$ 与 $t=\pm\pi$ 处的收敛值。

**它训练的识别点**：**$x(t)$ 不再是偶函数**，所以 $b_n \neq 0$，必须同时计算 $a_n$ 与 $b_n$——这直接检验「先判断奇偶性」这一步是否被机械套用。同时本题在 $t=0$ 处有跳变（$\lim_{t\to0^+}x(t)=0$，$\lim_{t\to0^-}x(t)=0$，实际都是 0，$x(0^+)=0$ 也在定义处连续），在 $t=\pm\pi$ 处由周期性产生的接缝需要用周期折算判断——两处都是讨论收敛值的不同情形。

**自测检查点**：先判断 $x(t)$ 的奇偶性并写下 $a_n$、$b_n$ 中哪些为零，再列出所有需要讨论的边界点。

**最终答案**：因 $x(t)$ 非奇非偶，$a_n$ 与 $b_n$ 均有贡献；系数为

$$
a_n = \frac{2}{\pi}\int_0^{\pi} t\cos(nt)\,\mathrm{d}t = \frac{2}{\pi}\left[\frac{t\sin(nt)}{n} + \frac{\cos(nt)}{n^2}\right]_0^{\pi} = \frac{2}{\pi}\cdot\frac{(-1)^n - 1}{n^2}
$$

$$
b_n = \frac{2}{\pi}\int_0^{\pi} t\sin(nt)\,\mathrm{d}t = \frac{2}{\pi}\left[-\frac{t\cos(nt)}{n} + \frac{\sin(nt)}{n^2}\right]_0^{\pi} = -\frac{2(-1)^n}{n}
$$

在 $t=0$ 处收敛到 $\frac{0+0}{2}=0$；在 $t=\pm\pi$ 处，由周期折算得左右极限均为 $\pi$ 与 $0$ 的组合，收敛到 $\frac{\pi+0}{2}=\frac{\pi}{2}$。

回复「讲解变式题」可看完整推导。
