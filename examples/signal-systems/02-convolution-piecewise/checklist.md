# 检查清单：连续时间卷积与分段讨论

**样本 id**：`signal-systems/02-convolution-piecewise`
**基线级别**：Tier A
**模式**：standard

## 本样本锁定的规则

| 规则位置 | 锁定内容 |
|---|---|
| `SKILL.md` §逐步推导 | 涉及卷积、积分区间时必须明确列出范围或状态变化 |
| `SKILL.md` §逐步推导 | 分段讨论不得跳步，区间划分依据要写清 |
| `SKILL.md` §核心原则 | 边界条件检查：本题需检查 t=0 与 t=1 处的连续性 |

## 判定条件

### 结构（机器可检）

- 章节必须出现：题型判断、第一眼突破口、逐步推导、解题思维复盘、核心套路总结、易错点、更快捷的方法、同类型变式题
- 关键词必须出现：

- `卷积` 必须出现
- `分段` 必须出现
- `积分区间` 必须出现

- 禁语不得出现在「逐步推导」节：`显然`、`容易得`、`同理可得`
- 章节必须缺席：

- （无）

### 关键结论（机器可检）

- 给出 y(t) 的分段表达式：命中 `(1-e^{-t})` / `1-e^{-t}` / `e^{-t}` 之一即可

### token 组合约束（机器可检）

- 包含 0<t<1 区间的结果 (1-e^{-t})；须同时出现 `1-e^{-t}` / `u(t)`
- 包含 t>1 区间的结果 e^{-(t-1)}-e^{-t}；须同时出现 `e^{-(t-1)}` / `e^{-t}`

### 结论必须缺席（机器可检）

- （无）

### 质量（人工或 judge）

- 维度 1（推导完整性）：必须写出积分上下限随 t 变化的三段讨论，不能只给最终分段式
- 维度 3（验算完备性）：需检查 t=0、t=1 处的连续性，并可用 $y'(t)$ 或冲激响应验证

## 判退场景

出现以下任一情况即判定不合格：

- 只给最终分段式而不解释积分区间如何划分
- 把 x2(t) 的两个阶跃项在一个积分里处理，导致区间讨论缺失
- 未检查 t=0 与 t=1 处的连续性

## 备注

本题是「积分区间 + 分段讨论」这一高风险规则的代表样本。$x_2$ 是宽度为 1 的矩形脉冲，卷积结果在 t=1 处发生斜率变化但不跳变，是检验边界条件检查的好题目。
