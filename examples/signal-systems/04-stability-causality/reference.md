# 参考输出：04 系统函数的因果性与稳定性判据

> 人工审定的基准输出。核心是 ROC 与因果性/稳定性判据的对应关系必须讲透。

## 题型判断与考点

**题型**：由系统函数求冲激响应，并判断因果性与稳定性。

**直接考点**：部分分式展开（含二次因子）；由收敛域决定信号形式。

**隐含考点**：
- 二次因子 $s^2+2s+2$ 需配方为 $(s+1)^2+1$，才能识别为衰减振荡；
- **因果性由 ROC 的形状决定，稳定性由 ROC 是否包含虚轴决定**——这是两个独立判据；
- 极点位置决定 ROC 的**边界**，但不直接决定稳定性。

**常用公式**：$\mathcal{L}\{e^{-at}\cos(\omega t)u(t)\} = \frac{s+a}{(s+a)^2+\omega^2}$；$\mathcal{L}\{e^{-at}\sin(\omega t)u(t)\} = \frac{\omega}{(s+a)^2+\omega^2}$。

**命题人想考察什么**：能否把「极点位置—ROC 形状—信号形式—因果性—稳定性」串成一条完整链条，而不是孤立地背结论。

## 第一眼突破口

**看到的第一样东西**：分母 $(s+2)(s^2+2s+2)$。

**由此联想到什么**：一次因子 $(s+2)$ 直接对应一个实极点 $-2$；二次因子 $s^2+2s+2$ **配方**得 $(s+1)^2+1$，对应共轭复极点 $-1 \pm j$，对应衰减振荡。

**关键的第二层观察**：分子 $s+1$ 与分母配方后的 $(s+1)^2+1$ 有呼应——$s+1 = (s+2)-1$，这个恒等式正是部分分式展开能凑出整齐形式的关键。

**因此选择的路线**：先配方识别极点，再用「待定系数 + 配方」展开为标准形式，最后按 ROC 分情况讨论。

**为什么 ROC 有两种可能**：题目只给了「收敛域为 $\mathrm{Re}(s)>-2$ 和 $\mathrm{Re}(s)<-2$」两种。这两种分别对应**最右极点右侧**与**最左极点左侧**，是仅有的两种「全右边」或「全左边」情形——因为三个极点 $-2, -1\pm j$ 把 $s$ 平面分为三段，而题目刻意排除了中间那条带状 ROC（那样会出现双边信号，更复杂）。

## 逐步推导

### 第一步：配方识别极点

**做什么**：把二次因子写成标准形式。

**依据**：$s^2+2s+2 = (s+1)^2+1$。

**极点**：$s = -2$；$s = -1+j$ 与 $s=-1-j$。

**目的**：知道有三个极点，且最右极点的实部为 $-1$，最左极点为实极点 $-2$。

### 第二步：部分分式展开

**做什么**：把 $H(s)$ 写成实极点项与共轭复极点项之和。

**依据**：标准展开形式

$$
H(s) = \frac{A}{s+2} + \frac{Bs+C}{(s+1)^2+1}
$$

**定系数**：两边同乘 $(s+2)((s+1)^2+1)$：

$$
s+1 = A((s+1)^2+1) + (Bs+C)(s+2)
$$

令 $s=-2$：$-1 = A(1+1) = 2A \Rightarrow A = -\frac{1}{2}$

展开剩余项，令 $s=0$：$1 = A(2) + 2C = -1 + 2C \Rightarrow C = 1$

比较 $s^2$ 项：$0 = A + B \Rightarrow B = \frac{1}{2}$

**核对 $s$ 项**：左边系数 1；右边 $2A + 2B + C = -1 + 1 + 1 = 1$ ✓

**故**：

$$
H(s) = -\frac{1}{2}\cdot\frac{1}{s+2} + \frac{\frac{1}{2}s + 1}{(s+1)^2+1}
$$

### 第三步：拆出可识别的变换对

**做什么**：把第二项改写成标准形式。

**依据**：$\frac{\frac{1}{2}s+1}{(s+1)^2+1} = \frac{\frac{1}{2}(s+1) + \frac{1}{2}}{(s+1)^2+1}$

**拆解**：

$$
\frac{\frac{1}{2}(s+1)}{(s+1)^2+1} + \frac{\frac{1}{2}}{(s+1)^2+1}
$$

第一项是 $\frac{1}{2}$ 乘以 $\frac{s+1}{(s+1)^2+1}$，对应 $\frac{1}{2}e^{-t}\cos t$；第二项是 $\frac{1}{2}$ 乘以 $\frac{1}{(s+1)^2+1}$，而 $\frac{1}{(s+1)^2+1} = \frac{1}{(s+1)^2+1^2}$ 对应 $e^{-t}\sin t$（因为 $\mathcal{L}\{e^{-at}\sin(\omega t)\} = \frac{\omega}{(s+a)^2+\omega^2}$，此处 $\omega=1$）。

**故**：

$$
H(s) = -\frac{1}{2}\cdot\frac{1}{s+2} + \frac{1}{2}\cdot\frac{s+1}{(s+1)^2+1} + \frac{1}{2}\cdot\frac{1}{(s+1)^2+1}
$$

**验证分子**：公分母后分子 $= -\frac{1}{2}(s+1)^2 - \frac{1}{2} + \frac{1}{2}(s+2) + \frac{1}{2}(s+1)^2 = -\frac{1}{2} + \frac{1}{2}s + 1 = \frac{1}{2}s + \frac{1}{2}$。与第二步结果一致 ✓

### 第四步：情况 1 — ROC 为 $\mathrm{Re}(s)>-2$

**做什么**：判断各项取右边还是左边。

**依据**：最右极点的实部为 $-1$，故 $\mathrm{Re}(s)>-2$ 这个 ROC **包含了**最右极点 $-1$（因为 $-1 > -2$）。这意味着所有项都取**右边信号**。

**逐项写出**：

$$
h(t) = -\frac{1}{2}e^{-2t}u(t) + \frac{1}{2}e^{-t}\cos t\, u(t) + \frac{1}{2}e^{-t}\sin t\, u(t)
$$

**目的**：完成因果情形的冲激响应。

**因果性判断**：所有项都含 $u(t)$，$t<0$ 时恒为零，**因果**。

**稳定性判断**：ROC 为 $\mathrm{Re}(s)>-2$，包含虚轴（$\mathrm{Re}(s)=0$ 落在 $-2$ 右侧），故**稳定**。

**等价验证**：$\int_0^{\infty}|h(t)|\,\mathrm{d}t \le \frac{1}{2}\int_0^\infty e^{-2t}\mathrm{d}t + \frac{1}{2}\int_0^\infty e^{-t}(\cos t + \sin t)\,\mathrm{d}t < \infty$，绝对可积，稳定 ✓

### 第五步：情况 2 — ROC 为 $\mathrm{Re}(s)<-2$

**做什么**：所有项都取左边信号。

**依据**：$\mathrm{Re}(s)<-2$ 位于最左极点 $-2$ 的左侧，三个项全部取**左边信号**，对应 $-e^{-at}u(-t)$ 形式。

**逐项写出**：注意系数与负号一起搬（左边信号形式自带负号）：

$$
h(t) = +\frac{1}{2}e^{-2t}u(-t) - \frac{1}{2}e^{-t}\cos t\, u(-t) - \frac{1}{2}e^{-t}\sin t\, u(-t)
$$

**说明**：第一项系数为 $-\frac{1}{2}$，取左边信号形式后变为 $+\frac{1}{2}e^{-2t}u(-t)$；后两项系数为正，取左边形式后带负号。

**因果性判断**：$t>0$ 时恒为零，是**反因果**信号，**非因果**。

**稳定性判断**：ROC 为 $\mathrm{Re}(s)<-2$，**不包含虚轴**（虚轴 $\mathrm{Re}(s)=0$ 不在此区域内），故**不稳定**。

**直观理解**：$t\to-\infty$ 时 $e^{-2t}\to+\infty$，$|h(t)|$ 在负半轴发散，不可积。

### 第六步：汇总判据

| ROC | 信号类型 | 因果性 | 稳定性 |
|---|---|---|---|
| $\mathrm{Re}(s)>-2$ | 全右边 | 因果 | 稳定 |
| $\mathrm{Re}(s)<-2$ | 全左边 | 非因果（反因果） | 不稳定 |

**为什么两种情况稳定性相反**：因果 ROC 必然是最右极点右侧的右半平面，它**包含**虚轴当且仅当最右极点的实部 $<0$；本题最右极点实部为 $-1<0$，故因果时稳定。反之，反因果 ROC 是最左极点左侧的左半平面，**永远不包含**虚轴，故反因果系统一定不稳定。

### 第七步：验算

**验算 1 — 代回原式**：把第三步的三个标准项通分，分子为 $\frac{1}{2}s+\frac{1}{2}$，分母为 $(s+2)((s+1)^2+1) = (s+2)(s^2+2s+2)$，故 $H(s) = \frac{\frac{1}{2}s+\frac{1}{2}}{(s+2)(s^2+2s+2)}$。与题目给的 $\frac{s+1}{(s+2)(s^2+2s+2)}$ 相比**分子差一个系数 2**。

**这里必须停一下**：验算不通过，说明系数求错了。回到第二步重查。

重新定系数：$s+1 = A((s+1)^2+1) + (Bs+C)(s+2)$

令 $s=-2$：左边 $-1$，右边 $A((-1)^2+1) = 2A$，故 $A = -\frac{1}{2}$ ✓

令 $s=0$：左边 $1$，右边 $A(1+1) + 2C = -1 + 2C$，故 $C = 1$ ✓

比较 $s^2$ 项：左边 0，右边 $A + B = 0$，故 $B = \frac{1}{2}$ ✓

比较 $s$ 项：左边 1，右边 $2A + 2B + C = -1 + 1 + 1 = 1$ ✓

常数项：左边 1，右边 $A + 2C = -\frac{1}{2} + 2 = \frac{3}{2}$ ✗

**常数项不匹配**——问题出在这里。$A((s+1)^2+1)$ 展开后常数项是 $A\cdot 2 = -1$，$(Bs+C)(s+2) = Bs^2 + (2B+C)s + 2C$ 常数项是 $2C = 2$。合计 $-1+2=1$ ✓ 与左边 1 相等。

我上面把 $A((s+1)^2+1)$ 的常数项算成了 $A$ 而非 $2A$，重新核对 $s=0$ 处的代入：$A((0+1)^2+1) + (B\cdot0+C)(0+2) = 2A + 2C = -1 + 2C = 1 \Rightarrow C = 1$ ✓

**结论**：系数 $A=-\frac{1}{2}, B=\frac{1}{2}, C=1$ 是对的。问题出在第三步的「拆出可识别变换对」。

重新拆：$\frac{Bs+C}{(s+1)^2+1} = \frac{\frac{1}{2}s+1}{(s+1)^2+1}$

改写分子：$\frac{1}{2}s + 1 = \frac{1}{2}(s+1) + \frac{1}{2}$

**这里错了**：$\frac{1}{2}(s+1) = \frac{1}{2}s + \frac{1}{2}$，再加 $\frac{1}{2}$ 得 $\frac{1}{2}s + 1$ ✓ 没错。

所以 $\frac{\frac{1}{2}s+1}{(s+1)^2+1} = \frac{1}{2}\cdot\frac{s+1}{(s+1)^2+1} + \frac{1}{2}\cdot\frac{1}{(s+1)^2+1}$ ✓

但注意 $\frac{1}{(s+1)^2+1}$ 对应的逆变换是 $\frac{1}{1}\cdot e^{-t}\sin t = e^{-t}\sin t$，系数是 1（因为 $\frac{\omega}{(s+a)^2+\omega^2}$ 中 $\omega=1$，分子就是 $\omega=1$，所以 $\frac{1}{(s+1)^2+1}$ 确实对应 $e^{-t}\sin t$，系数为 $\frac{1}{\omega}=1$）✓

那分子为何对不上？重新通分：

$$
-\frac{1}{2}\cdot\frac{1}{s+2} + \frac{1}{2}\cdot\frac{s+1}{(s+1)^2+1} + \frac{1}{2}\cdot\frac{1}{(s+1)^2+1}
$$

通分到公分母 $(s+2)((s+1)^2+1)$：

分子 $= -\frac{1}{2}\big((s+1)^2+1\big) + \frac{1}{2}(s+1)(s+2) + \frac{1}{2}(s+2)$

$= -\frac{1}{2}(s^2+2s+2) + \frac{1}{2}(s^2+3s+2) + \frac{1}{2}(s+2)$

$= \left(-\frac{1}{2}+\frac{1}{2}\right)s^2 + \left(-1+\frac{3}{2}+\frac{1}{2}\right)s + \left(-1+1+1\right)$

$= 0\cdot s^2 + 1\cdot s + 1$ ✓

分子是 $s+1$ ✓ —— 之前的核对把 $\frac{1}{2}(s+1)(s+2)$ 的 $s^2$ 系数写成了 0，漏掉了 $\frac{1}{2}$。

**最终验算通过**：

$$
H(s) = \frac{s+1}{(s+2)(s^2+2s+2)} \checkmark
$$

**这一步的意义**：验算不是形式主义。上面两次「不通过」分别暴露了核对常数项时的算术错误，与通分时漏项的错误。这说明**必须用统一的方式通分核对**，逐项心算容易出错。

## 解题思维复盘

**从题目特征回到方法选择**：看到二次分母先配方，看到「两种 ROC」先想清楚最右/最左极点在哪里。

**为什么判据要分开讲**：初学者常把「因果」与「稳定」混为一谈。本题提供了完美的反例对照——**同一组极点，只因 ROC 不同，一个稳定一个不稳定**。所以必须说清：因果性看 ROC 是否在最右极点右侧，稳定性看 ROC 是否包含虚轴。

**常见错误路线为什么走不通**：
- 「三个极点都在左半平面，所以系统稳定」——错。稳定要看 ROC 是否含虚轴。反因果情形的 ROC 在左半平面，同样不含虚轴，仍不稳定。
- 「反因果系统一定不稳定」——**这个结论其实是对的**，但理由必须说清（反因果 ROC 在最左极点左侧，必不含虚轴），而不是当作口号。

## 核心套路总结

> **看到什么 → 想到什么 → 怎么做 → 检查什么**

**看到什么**：有理式系统函数 + 若干 ROC 条件。

**想到什么**：先配方定极点 → 再部分分式展开 → 再由 ROC 逐项定信号形式 → 最后用两条判据判因果与稳定。

**怎么做**：
1. 分母配方，列出全部极点，标出最右与最左；
2. 部分分式展开：实极点一项，共轭复极点一项（保留分子 $Bs+C$）；
3. 把 $Bs+C$ 改写为 $\frac{B}{2}(s+a) + \left(C - \frac{Ba}{2}\right)$ 的形式，凑成标准变换对；
4. 由 ROC 逐项判断取右边还是左边信号（左边形式自带负号）；
5. 因果性：全部项含 $u(t)$ 则因果；稳定性：ROC 是否含虚轴。

**检查什么**：通分核对分子（要一次性写全三项的贡献）；用 $\int|h|$ 可积性做等价验证；对照「因果 ROC 在最右极点右侧」「反因果 ROC 必不含虚轴」这两条结构性结论。

## 易错点

1. **错误表现**：说「极点都在左半平面，所以系统稳定」。
   **错误原因**：混淆极点位置与稳定性判据。
   **避免方法**：稳定性只看 ROC 是否含虚轴。本题两种 ROC 一个含一个不含，结论相反。

2. **错误表现**：反因果情形忘记负号，写成 $h(t) = \frac{1}{2}e^{-2t}u(-t) + \frac{1}{2}e^{-t}\cos t\,u(-t) + \frac{1}{2}e^{-t}\sin t\,u(-t)$。
   **错误原因**：左边信号形式 $\mathcal{L}^{-1}\{\frac{1}{s+a}\} = -e^{-at}u(-t)$ 自带负号。
   **避免方法**：展开时对每一项单独写「系数 × 左边形式」，不要整体套符号。

3. **错误表现**：二次因子不配方，展开后得到无法识别的分式。
   **错误原因**：未意识到 $(s+1)^2+1$ 才是可用的形式。
   **避免方法**：见到二次分母，第一步就配方。

4. **错误表现**：把 $Bs+C$ 中的 $C$ 直接当作 $\frac{\omega}{(s+a)^2+\omega^2}$ 的分子。
   **错误原因**：忽略了改写分子那一步的常数项调整。
   **避免方法**：把 $Bs+C$ 写成 $\frac{B}{2}(s+a) + \left(C - \frac{Ba}{2}\right)$，再对应变换对。

5. **错误表现**：验算时只核对部分项就宣布通过。
   **错误原因**：通分核对时漏项。
   **避免方法**：一次性写出三项的分子贡献再合并，不要逐项心算。

## 更快捷的方法

**方法**：记住结构化判据表，直接由 ROC 与极点的相对位置读出结论：

- ROC 在最右极点右侧 → 因果；该情形下稳定 ⟺ 最右极点实部 $<0$
- ROC 在最左极点左侧 → 反因果 → 必不稳定
- ROC 为跨越极点的带状 → 双边；稳定 ⟺ 带包含虚轴

**适用条件**：有理式系统函数，分母已完全分解。

**快在哪里**：跳过逐项判断的叙述，直接给结论。

**为什么成立**：这是部分分式展开后每项独立选择 ROC 的结构性推论。

**说明**：本题中标准解法更完整，因为题目明确要求「说明依据」——快捷法只适合心算核对。

## 同类型变式题

**变式题**：已知 $H(s) = \frac{s-1}{(s+1)(s^2+4)}$，求冲激响应（分别讨论 $\mathrm{Re}(s)>-1$ 与 $\mathrm{Re}(s)<-2$ 两种 ROC），并判断因果性与稳定性。

**它训练的识别点**：二次因子 $s^2+4$ 不含一次项，需配方为 $s^2+2^2$，对应**无衰减**的纯振荡 $2\sin 2t$——这与原题的有衰减振荡形成对照，能暴露模型是否真的做了配方而非套模板。同时极点变为 $-1$ 与 $\pm 2j$，最右极点实部为 $-1$，最左为实极点 $-2$（来自 $-1$？不，极点为 $-1, \pm 2j$，最右极点实部为 $0$，在虚轴上）。

**这带来一个重要变化**：最右极点实部为 0（极点 $\pm 2j$ 恰在虚轴上），因此**因果情形下 ROC 为 $\mathrm{Re}(s)>0$，不包含虚轴，系统不稳定**——因为冲激响应含不衰减的振荡项。这正是「因果 ⟹ 稳定」不成立的典型例子。

**自测检查点**：先写出三个极点 $-1, 2j, -2j$，判断最右极点实部是否为 0。

**最终答案**：

$$
H(s) = -\frac{1}{3}\cdot\frac{1}{s+1} + \frac{1}{3}\cdot\frac{s+1}{s^2+4} + \frac{2}{3}\cdot\frac{1}{s^2+4}
$$

ROC 为 $\mathrm{Re}(s)>0$ 时 $h(t) = -\frac{1}{3}e^{-t}u(t) + \frac{1}{3}\cos 2t\,u(t) + \frac{1}{3}\sin 2t\,u(t)$，因果但**不稳定**（虚轴在极点处，不属于 ROC）。
