# 样本：01 双边拉普拉斯逆变换与收敛域

## 学科

信号与系统

## 题目

已知信号 $f(t)$ 的双边拉普拉斯变换为

$$
F(s) = \frac{1}{(s+1)(s+2)}
$$

分别求下列三种收敛域情况下的原信号 $f(t)$：

1. $\mathrm{ROC}: \mathrm{Re}(s) > -1$
2. $\mathrm{ROC}: -2 < \mathrm{Re}(s) < -1$
3. $\mathrm{ROC}: \mathrm{Re}(s) < -2$

并说明每种情况下信号的因果性，以及对应系统是否为稳定系统。

## 附加要求

请说明第一眼突破口，并解释为什么同一对极点会因收敛域不同而对应完全不同的信号。
