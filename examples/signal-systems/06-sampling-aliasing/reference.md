# 参考输出：06 奈奎斯特采样与频谱混叠

> 人工审定的基准输出。核心是逐个分量与奈奎斯特频率比较，以及混叠频率的正确计算。

## 题型判断与考点

**题型**：采样定理的适用性判断与频谱混叠分析。

**直接考点**：奈奎斯特采样定理；采样后频谱的周期性搬移。

**隐含考点**：
- 混叠（aliasing）与量化误差是**两种不同的失真**，前者不可恢复，后者可用更大量化比特压制；
- 多个频率分量可能**折叠到同一频率**上，造成信息永久丢失；
- 采样后的频谱是**周期延拓**的副本，周期为采样频率。

**常用公式**：若 $x(t)$ 的最高频率为 $f_m$，无失真恢复要求 $f_s > 2f_m$（奈奎斯特采样率 $f_N = 2f_m$）。采样后频谱 $X_s(j\omega) = \frac{1}{T}\sum_k X\left(j\left(\omega-\frac{2\pi k}{T}\right)\right)$。

**命题人想考察什么**：不仅判断「能否恢复」，还要算出「恢复出来的到底是什么」。

## 第一眼突破口

**看到的第一样东西**：$f_s = 1200\ \mathrm{Hz}$，信号含 $800\ \mathrm{Hz}$ 与 $1600\ \mathrm{Hz}$ 两个分量。

**由此联想到什么**：奈奎斯特频率 $f_N = f_s/2 = 600\ \mathrm{Hz}$。立刻看出 $800 > 600$ 且 $1600 > 600$，**两个分量都会混叠**，不是一个。

**关键的第二层观察**：$800$ 与 $1600$ 分别与 $1200$ 的差是 $400$ 和 $400$——**两个分量折叠到同一个频率**。这是本题精心设计的陷阱：即使采样率满足「看起来够用」的直觉，也无济于事，因为信息已经不可逆地重叠了。

**因此选择的路线**：先算奈奎斯特频率，再对每个分量单独做「折叠」计算，最后判断是否发生重叠。

## 逐步推导

### 第一步：计算奈奎斯特频率

**做什么**：求出允许的最高频率。

**依据**：$f_N = f_s/2$。

**计算**：

$$
f_N = \frac{1200}{2} = 600\ \mathrm{Hz}
$$

**结论**：信号最高频率 $f_m = 1600\ \mathrm{Hz} > 600\ \mathrm{Hz}$，不满足无失真采样条件，**会发生混叠**。

**严格说明**：严格无失真恢复要求 $f_s > 2f_m = 3200\ \mathrm{Hz}$。$1200\ \mathrm{Hz}$ 远低于此。

### 第二步：建立混叠的计算规则

**做什么**：推导单个频率分量折叠后的等效频率。

**依据**：采样后频谱是原频谱以 $f_s$ 为周期的延拓副本：

$$
X_s(f) = \frac{1}{T}\sum_{k=-\infty}^{\infty} X\left(f-kf_s\right)
$$

**对单一余弦分量**：$x(t) = \cos(2\pi f_0 t)$ 采样后，数字频率为 $\frac{f_0}{f_s}$ 周期/采样。等效频率是 $f_0$ 对 $f_s$ 取模后折到 $[-\frac{f_s}{2}, \frac{f_s}{2}]$ 内的结果：

$$
f_{\text{eq}} = f_0 - kf_s, \qquad k = \text{使 } |f_{\text{eq}}| \le \frac{f_s}{2} \text{ 的整数}
$$

**等价写法**：$f_{\text{eq}} = |f_0 - \text{round}(f_0/f_s)\cdot f_s|$

**为什么是折到 $[-f_s/2, f_s/2]$**：因为超过奈奎斯特频率的频率与其「镜像」在采样点上不可区分——因为 $f$ 与 $f+nf_s$ 在采样时刻 $t=nT$ 取值相同。

**目的**：得到可直接套用的计算工具。

### 第三步：分量 1 —— 800 Hz

**做什么**：计算折叠结果。

**依据**：$f_0 = 800\ \mathrm{Hz}$，$f_s = 1200\ \mathrm{Hz}$。

**确定 $k$**：$800/1200 = 0.667$，四舍五入得 $k=1$，故 $f_{\text{eq}} = 800 - 1\times 1200 = -400$，取绝对值得 $400\ \mathrm{Hz}$。

**校验折叠范围**：$|{-400}| = 400 \le 600$ ✓ 在有效范围内。

**结论**：$800\ \mathrm{Hz}$ 分量采样后表现为 $400\ \mathrm{Hz}$。

**为什么不折叠到 $800$ 本身**：因为 $800 > 600$ 超出奈奎斯特频率，采样点上 $800\ \mathrm{Hz}$ 与 $400\ \mathrm{Hz}$ 完全无法区分——验证：$t=nT$ 时，$\cos(2\pi\cdot 800\cdot n/1200) = \cos(2\pi\cdot 0.667n)$，而 $\cos(2\pi\cdot 400\cdot n/1200) = \cos(2\pi\cdot 0.333n) = \cos(2\pi n - 2\pi\cdot 0.667n) = \cos(2\pi\cdot 0.667n)$（余弦为偶函数且 $2\pi n$ 为整数倍），两者取值完全相同。

### 第四步：分量 2 —— 1600 Hz

**做什么**：同样计算。

**依据**：$f_0 = 1600\ \mathrm{Hz}$。

**确定 $k$**：$1600/1200 = 1.333$，四舍五入得 $k=1$，故 $f_{\text{eq}} = 1600 - 1200 = 400$，绝对值 $400\ \mathrm{Hz}$。

**校验**：$400 \le 600$ ✓

**结论**：$1600\ \mathrm{Hz}$ 分量同样折叠为 $400\ \mathrm{Hz}$。

### 第五步：识别重叠——本题的核心结论

**做什么**：比较两个分量的折叠结果。

**依据**：第三步与第四步的结果。

**结论**：两个分量**都折叠到 $400\ \mathrm{Hz}$**。

**这意味着什么**：采样后的信号

$$
x_s(t) = \cos(2\pi\cdot 400 t) + \cos(2\pi\cdot 400 t) = 2\cos(2\pi\cdot 400 t)
$$

两个余弦**同频叠加，振幅翻倍**，成为单一频率的正弦型信号。

**信息损失的严重性**：原本 $800$ 与 $1600$ 两个独立频率分量的**幅度、相位信息全部丢失**，且因为二者频率比恰为整数倍（$1600 = 2\times 800$），相位关系也无法帮助区分。**这种混叠是不可逆的**，任何后处理都无法恢复。

**实用推论**：若要无失真恢复，至少需要 $f_s > 2\times 1600 = 3200\ \mathrm{Hz}$。

### 第六步：验算

**验算 1 — 直接在采样点验证**。设 $T = 1/1200\ \mathrm{s}$。

原信号在 $t=nT$ 处的值：
$\cos(2\pi\cdot 800\cdot n/1200) + \cos(2\pi\cdot 1600\cdot n/1200) = \cos(2\pi n/3) + \cos(4\pi n/3)$

（因 $800/1200 = 2/3$，$1600/1200 = 4/3$）

等效信号在 $t=nT$ 处的值：
$2\cos(2\pi\cdot 400\cdot n/1200) = 2\cos(2\pi n/3)$

**核对**：当 $n=1$ 时，原信号 $= \cos(2\pi/3) + \cos(4\pi/3) = -0.5 + (-0.5) = -1$；等效信号 $= 2\cos(2\pi/3) = 2\times(-0.5) = -1$ ✓

当 $n=2$ 时，原信号 $= \cos(4\pi/3)+\cos(8\pi/3) = -0.5 + (-0.5) = -1$（因 $\cos(8\pi/3)=\cos(2\pi/3)=-0.5$）；等效 $= 2\cos(4\pi/3) = -1$ ✓

**验算 2 — 频谱搬移核对**：采样后频谱在 $f = \pm400\ \mathrm{Hz}$ 处各有一个余弦分量的贡献（原 $800$ 与 $1600$ 分别搬移而来），叠加后为单一 $400\ \mathrm{Hz}$ 分量，幅度为两者之和 ✓

**验算通过。**

## 解题思维复盘

**从题目特征回到方法选择**：看到「采样频率 + 多个频率分量」，第一步永远是算奈奎斯特频率并与各分量逐一比较。

**为什么本题不能停在「不能恢复」**：题目明确问「混叠后实际得到的信号」，这要求把折叠算到底。而且本题的特殊性在于**两个分量折叠到同一点**——只做「逐个折叠」还不够，必须**比较各分量的折叠结果**，才能发现重叠。

**常见错误路线为什么走不通**：
- 只判断「$f_s < 2f_m$，不能恢复」就收工——漏掉了题目第二问；
- 折叠时忘了取绝对值或忘了折到 $[-f_s/2, f_s/2]$——得到 $800-1200 = -400$ 或 $1600-1200=400$ 后未核对范围；
- 误以为 $800\ \mathrm{Hz}$ 不受影响（因为 $800 < 1200$）——把采样频率当成了奈奎斯特频率，这是最常见的错误；
- 认为两个分量折叠后仍是两个 $400\ \mathrm{Hz}$ 分量因而「还能分开」——**同频无法分离**，这是本题最需要点破的一步。

## 核心套路总结

> **看到什么 → 想到什么 → 怎么做 → 检查什么**

**看到什么**：采样频率 $f_s$ 与若干频率分量。

**想到什么**：先算 $f_N=f_s/2$，再逐个分量做模 $f_s$ 折叠。

**怎么做**：
1. 算 $f_N = f_s/2$；
2. 逐个分量算 $k=\text{round}(f_0/f_s)$，得 $f_{\text{eq}} = |f_0-kf_s|$；
3. 校验 $|f_{\text{eq}}| \le f_N$；
4. **比较各分量的 $f_{\text{eq}}$**，检查是否重叠；
5. 重叠时写出合并后的实际信号。

**检查什么**：是否有分量折叠到同一点；等效信号在采样点上是否与原信号取值一致（用几个具体 $n$ 值验算）；恢复所需的最低采样率。

## 易错点

1. **错误表现**：认为 $800\ \mathrm{Hz}$ 分量不受影响，因为 $800 < f_s$。
   **错误原因**：把采样频率当成了奈奎斯特频率。
   **避免方法**：判据是 $f_s > 2f_m$，即每个分量都要与 $f_s/2$ 比较，不是与 $f_s$ 比较。

2. **错误表现**：只回答「不能无失真恢复」，未算混叠后的频率。
   **错误原因**：把题目两问当成一问。
   **避免方法**：逐字读题，确认每一个问；本题第二问才是区分度所在。

3. **错误表现**：折叠后未比较各分量是否落到同一频率，答成「两个 400 Hz 分量」。
   **错误原因**：止步于逐个计算，未做横向比较。
   **避免方法**：算出所有 $f_{\text{eq}}$ 后，专门做一步「是否重合」的检查，并明确说明同频不可分离。

4. **错误表现**：折叠时用 $f_0 - f_s$ 而不做 round，导致 $1600\ \mathrm{Hz}$ 分量算成 $1600-1200=400$ 但 $800$ 分量算成 $800-1200=-400$ 后未取绝对值。
   **错误原因**：漏掉取绝对值。
   **避免方法**：套用 $f_{\text{eq}} = |f_0 - \text{round}(f_0/f_s)\cdot f_s|$ 这一完整公式。

5. **错误表现**：把混叠与量化误差混为一谈。
   **错误原因**：两者都是「采样后失真」，但机理与可恢复性完全不同。
   **避免方法**：混叠是频域重叠，**不可逆**；量化是幅度离散化，增加量化比特即可压制。

## 更快捷的方法

**方法**：直接用「$f_s$ 折叠」的图像化理解——把频率轴按 $f_s$ 折成「手风琴」，每个分量落到折痕的哪一格就是它的等效频率。

**适用条件**：任意采样情形。

**快在哪里**：不必逐个算 round，直接在数轴上折叠即可，方向与幅度一目了然。

**为什么成立**：这是采样后频谱周期延拓的几何表述。

**说明**：本题中标准解法（逐个计算）已足够清晰；快捷法适合心算与画图辅助。

## 同类型变式题

**变式题**：信号 $x(t) = \cos(2\pi\cdot 500 t) + \cos(2\pi\cdot 700 t)$，以 $f_s = 1000\ \mathrm{Hz}$ 采样。判断能否无失真恢复，并求混叠后的等效信号。

**它训练的识别点**：$700\ \mathrm{Hz}$ 分量折叠为 $|700-1000| = 300\ \mathrm{Hz}$，而 $500\ \mathrm{Hz}$ 分量恰好等于奈奎斯特频率 $f_N=500$——**边界情形**。当分量正好落在 $f_N$ 上时，折叠结果恰好是 $500$（因 $500-1000=-500$，取绝对值为 $500$，恰在奈奎斯特频率上），采样点在 $t=nT$ 处该分量的值为 $\cos(\pi n) = (-1)^n$，这是可恢复的（不产生不可消除的歧义），但这是**边界**上的情形，需要单独说明而不能套用「折叠」的常规叙述。

**同时**：两个分量折叠后分别为 $500$ 与 $300$，**不重叠**，因此可以恢复出「两个不同频率」但**无法恢复原频率**（$500$ 与 $700$ 不可区分于 $500$ 与 $-300$）。这与原题形成对照——原题是重叠，本题是不重叠。

**自测检查点**：先算 $f_N=500$，注意 $500$ 恰好等于 $f_N$ 这一边界，再逐个折叠并比较。

**最终答案**：$f_s = 1000 < 2\times 700 = 1400$，不能无失真恢复。等效信号为 $\cos(2\pi\cdot 500 t) + \cos(2\pi\cdot 300 t)$，两分量不重叠，频率可分辨但不可还原为原始的 $500$ 与 $700$。

回复「讲解变式题」可看完整推导。
